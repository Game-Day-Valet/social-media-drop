# social-media-drop

Public, temporary hosting for **approved** Sideline and GDV social graphics, used only so Metricool can fetch them at scheduling time.

- The content engine (Game-Day-Valet/sideline-gdv-content-engine) pushes a render here only after it passes every quality check.
- Metricool copies the file to its own storage when the post is scheduled. The engine then deletes the file from this repo.
- Held, draft, or private media (event photos on hold, customer data) is never pushed here.

Do not store anything here that should not be public.
